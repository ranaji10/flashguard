# Superseded proposal drafts

Long-form answers written before the real NLnet form was known. **Not the submission.**

The form is two free-text boxes, not seven questions (see
`grant/nlnet-findings-2026-09-03.md` §3). These drafts are kept because their substance is
the raw material for box 9, box 11 and the attachment — the synthesis, not the shape.

This folder exists so drafts do **not** go into `library/`. That folder holds borrowed,
differently-licensed third-party material behind the project/library wall, and putting our
own work in it breaks the one rule it exists to enforce.

Nothing here is authoritative. The live proposal is `grant/nlnet-restack-proposal.md`.
