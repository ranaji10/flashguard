WebUSB probe

Reads USB descriptors in the browser and prints the fields classify.sh classifies on. Nothing is claimed, transferred or written. Chrome or Edge only.

What this decides. If the interface classes printed here match the ones in tests/real-descriptors/ for the same device, then identifying and classifying a device needs no install and no Linux stick, and the bench kit's Ubuntu requirement can go. The Android fingerprint is a separate question: it needs interface claiming, which this probe deliberately does not attempt.
